# Sistema de Automação de Produtos

Projeto desenvolvido em Python com foco em automação de tarefas relacionadas a produtos, utilizando scripts para otimizar processos repetitivos e aumentar a produtividade.

## Sobre o Projeto

Este projeto foi criado com o objetivo de praticar automação de processos utilizando Python.

Os scripts desenvolvidos permitem automatizar tarefas e auxiliar na execução de ações repetitivas de forma mais rápida e eficiente.

No arquivo `automacao.py` é realizada a automação principal do projeto.

No arquivo `posicaomouse.py` é possível capturar posições do mouse para auxiliar na configuração da automação.

## Funcionalidades

- Automação de tarefas
- Captura de posição do mouse
- Execução de processos automáticos
- Otimização de tarefas repetitivas

## Tecnologias Utilizadas

- Python
- PyAutoGUI
- Automação de Processos

## Aprendizados

Durante o desenvolvimento deste projeto foram praticados conceitos como:

- Automação com Python
- Captura de coordenadas do mouse
- Execução automática de tarefas
- Organização de scripts
- Produtividade com automação
